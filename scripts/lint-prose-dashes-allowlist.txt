# W-21 allowlist: em and en dashes that are typography, not prose.
#
# The lint beside this file (scripts/lint-prose-dashes.py) refuses an em dash (U+2014) or an
# en dash (U+2012, U+2013) inside a string a user reads, because published copy here is
# written with the punctuation the sentence actually wants instead. A handful of dashes are
# not sentences at all: a glyph standing in for a value that is missing, a separator between
# two metadata fields, a range of keys or letters. Those belong here, each under a line
# saying why, rather than being rewritten into something worse.
#
# POLICY FOR SHIPPED HISTORY: old What's New entries keep the prose that shipped. A
# `history-from` entry names the first old release by its exact version line. An optional end
# marker limits the exemption to the release-note array when other UI code follows it. Release
# lists are newest first, so new notes inserted above the start marker remain subject to the
# lint. Every marker must match exactly once or the lint fails.
#
# FORMAT: the usual form is the repo-relative path, a TAB, then the trimmed text of one source
# line. A history boundary is path, TAB, `history-from`, TAB, then the trimmed version line.
# It can add a TAB and a trimmed end marker; the end marker itself is not exempt.
# Neither form uses a line number, which would rot the moment anything above it moved, and
# neither exempts a whole file. Rewriting an exact line or moving a history marker stops the
# entry matching, which is the point: each exemption stays tied to the text it was granted to.
#
# Adding an entry is a copy decision. If the dash is doing the work of a period, a colon, a
# pair of parentheses or a comma, it is prose and belongs in the sentence, not in here.

# --- Characters needed to parse or trim text, not prose -----------------------
# The literal dash glyphs are members of a CharacterSet used to strip dangling separator
# punctuation from a downloaded filename ("{artist} - {title}" with no artist becomes
# " - Title", trimmed to "Title"). Rewriting the sentence is not possible here: there is no
# sentence, the characters themselves are the thing being matched, and removing either one
# from the set would leave that punctuation in a filename it should have been trimmed from.
Packages/BatonPlaybackKit/Sources/BatonPlaybackKit/MusicDownloadStore.swift	let trimSet = CharacterSet(charactersIn: " -_.–—").union(.whitespaces)
